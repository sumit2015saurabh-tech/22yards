# 22yards — Cricket Entertainment Frontend

React + Vite + Tailwind. Connects to microservices API gateway at `localhost:8080`.

## Dev

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

```bash
GITHUB_PAGES=true npm run deploy
```

Live at: https://itsageek.github.io/22yards/

## Compliance features

- 18+ age gate
- Cookie consent
- Terms, Privacy, Responsible Play pages
- Self-exclusion in profile
- Virtual points disclaimers throughout
